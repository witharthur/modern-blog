**1\. What is Bootstrap?**\
Bootstrap is a popular front-end framework used to design responsive and mobile-first websites easily. It provides pre-built CSS and JavaScript components like grids, buttons, forms, and navigation bars.

* * * * *

**2\. How to include Bootstrap in a project?**\
You can include Bootstrap either by linking to its CDN (online version) or by downloading the Bootstrap files and adding them to your project locally.

* * * * *

**3\. What is the grid system?**\
The grid system in Bootstrap is a layout structure that divides the page into rows and columns. It helps arrange content responsively so that it automatically adjusts to different screen sizes.

* * * * *

**4\. What are utility classes?**\
Utility classes are small, predefined classes in Bootstrap used for quick styling, such as margins, padding, colors, alignment, and text formatting, without writing custom CSS.

* * * * *

**5\. How do you customize Bootstrap?**\
Bootstrap can be customized by overriding its default CSS styles, changing its variables using Sass, or adding custom styles in a separate CSS file.

* * * * *

**6\. Difference between `container` and `container-fluid`?**

-   **container**: Has fixed width that adjusts at different screen breakpoints.

-   **container-fluid**: Always takes up the full width of the screen, regardless of size.

* * * * *

**7\. What are Bootstrap cards?**\
Cards are flexible content containers in Bootstrap used to display information like images, titles, text, and links in a structured and modern layout.

* * * * *

**8\. How to make responsive navigation?**\
Bootstrap provides a navigation bar (navbar) that automatically collapses into a toggle menu on smaller screens, making it responsive without extra coding.

* * * * *

**9\. What is a CDN?**\
CDN (Content Delivery Network) is a network of servers that delivers web resources like CSS, JS, or images quickly to users from the nearest server location.

* * * * *

**10\. How to override Bootstrap styles?**\
You can override Bootstrap styles by adding your own CSS rules after the Bootstrap file in your HTML, using more specific selectors, or using `!important` if necessary.
