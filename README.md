# ModernBlog

A modern, responsive blog template built with Bootstrap 5 featuring vibrant gradient backgrounds and smooth animations.

![Bootstrap](https://img.shields.io/badge/Bootstrap-5.3.2-purple?style=flat&logo=bootstrap)
![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white)

## Features

- Gradient card headers with animated icons
- Fully responsive design
- Smooth hover animations and transitions
- Sticky navbar with mobile menu
- Interactive blog cards
- Social media footer

## Quick Start

1. Clone the repository
2. Open `index.html` in your browser
3. No installation needed

## Technologies

- Bootstrap 5.3.2
- Bootstrap Icons 1.11.1
- Vanilla JavaScript
- CSS3 Animations

## Responsive Design

- Large screens: 3 cards per row
- Medium screens: 2 cards per row  
- Small screens: 1 card per row

## Customization

Edit CSS variables in `styles.css`:

```css
:root {
    --primary-color: #6366f1;
    --secondary-color: #8b5cf6;
}
```
